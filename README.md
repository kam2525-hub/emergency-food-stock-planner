# 防災備蓄ローリングストック期限＆必要量シミュレーター

家族人数と備蓄日数から必要な非常食・水の量を自動算出し、手持ち備蓄の賞味期限と消費サイクルを管理できるツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/emergency-food-stock-planner/）。
2. 画面の指示に従って操作します。
